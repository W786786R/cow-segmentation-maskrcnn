# cow-segmentation-maskrcnn
Instance segmentation of cows in images using a fine-tuned Mask R-CNN (ResNet-50 + FPN) model built with PyTorch.

## 📌 Features
- Custom COCO-format dataset loader for cow segmentation
- Fine-tuned Mask R-CNN (ResNet-50 + FPN) pretrained on COCO
- Training pipeline with learning rate scheduling
- Prediction visualization (original image, ground truth mask, predicted mask)

## 🛠️ Tech Stack
- PyTorch & Torchvision
- pycocotools
- NumPy, Matplotlib, PIL
